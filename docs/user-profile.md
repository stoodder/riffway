# Player profile (from brainstorm, 2026-11-19)

Shapes defaults, difficulty calibration, starter library and recommendations.

| Topic | Answer | Design implication |
|---|---|---|
| Skill | Beginner–intermediate | Starter library authored for tiers 1–6 of 10 (computed ratings land at 1–5, each within ±1 of its target, T-029); recommendations target "stretch" songs ~1 tier above comfort |
| Taste | Rock, metal, really everything — especially **recognizable** songs; wants to **play for others** | Starter library favours recognizable public-domain melodies in rock/metal arrangements; "performance ready" milestone (full run, no slowdown, ≥90%) |
| Goals | Expand skill set, grow repertoire, improve on difficult songs | Skill tags per song, section mastery + looping/speed trainer for hard parts, repertoire count |
| Handedness | Right-handed | No mirroring by default (left-handed toggle is a nice-to-have) |
| Listening | Headphones or speakers | Monitoring on by default, headphones recommended in UI, feedback warning when output is built-in speakers |
| Backing audio | None — synthesized guide | Guide synth is first-class; audio attach still supported |
| Existing tabs | None | Starter library + ClassTab + free packs must make the app useful on day one |
| Technique | Plays with a pick; wants fingerstyle later | Songs tagged `pick` / `fingerstyle`, filterable; ClassTab (fingerstyle) included but not pushed by default |
| Visual style | Mix of Guitar Hero and Rocksmith | Dark, clean Rocksmith-like highway + punchy GH-style hit feedback, combo flames, star meter |
